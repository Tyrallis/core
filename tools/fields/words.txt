# How the words of the client's field names are spelled in the code names of
# sdk/include/wxl/update_fields.def, for the words the client runs together.
#
# A code name is the client's name with the kind's prefix dropped and each word, as the
# underscores split it, capitalised: UNIT_FIELD_LEVEL is Level. A client word that holds several
# words -- MAXHEALTH, DISPLAYID -- would read Maxhealth and Displayid; a line here spells it
# instead, the way the object getters name the same value (unit_max_health is MaxHealth):
#
#   <CLIENT WORD> <Spelling>
#
# A word ending in digits is looked up without them, and they are kept: MAXPOWER1 is MaxPower1.
# generate_update_fields.py reads this file and fails on a word no field uses, on a spelling that
# is not an identifier, and on two fields of a kind that would share a name.
